# Edge grass sprite versions
Kept for comparison; none of these files are compiled. The live art is `game/grassClumps.ts` and its placement in `game/paving.ts`.
- `v1-bushy.grassClumps.ts.txt`: first hand-drawn set, broad bodies that merged into a scalloped ribbon.
- `v2-leaves.grassClumps.ts.txt` + `v2-leaves.paving.ts.txt`: thin 1px leaves, rotated perpendicular to every edge (the left edge read as horizontal comb teeth).
- Current (v3): upright tufts with a small connected base and 2-3 uneven, tapered leaves, on every edge.
To compare, copy a version's files over the live ones (the `.ts.txt` suffix removed), or diff against them.
