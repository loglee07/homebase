# Finance Town

A cozy pixel-art town for your finances. Sample data only. See `CLAUDE.md` and `docs/progress.md`.

```bash
npm install
npm run dev   # http://localhost:3000
```

Walk with WASD/arrows to the bank door, press **E** (or use the **Bank** button). Use the **Demo control** to push sample net worth past $100,000 and watch the home upgrade.
